# Changelog

All notable changes to SafariSmart Kenya will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-11-18

### Added
- AI-powered trip planning using Google Gemini API
- 20+ Kenya destinations with detailed information
- Step-by-step wizard for itinerary creation
- Real-time weather forecasts for all destinations
- Interactive maps with Leaflet
- User authentication and account management
- Security features (rate limiting, CSRF protection, Django Axes)
- Modern, responsive design with Kenya-inspired theme
- SEO optimization with structured data
- Social sharing capabilities
- Analytics and API usage tracking

### Features
- Smart itinerary generation based on budget, duration, and interests
- Destination recommendations
- Budget optimization
- Travel group customization
- Interest-based activity suggestions
- Mobile-responsive design
- Fast page loads with optimized assets

### Security
- Multi-layer abuse prevention
- Rate limiting on API endpoints
- Secure password hashing with Argon2
- CSRF and XSS protection
- Content Security Policy implementation

## Version Numbering

We use [Semantic Versioning](https://semver.org/):
- **MAJOR** version (1.x.x) - Incompatible API changes
- **MINOR** version (x.1.x) - New features, backwards compatible
- **PATCH** version (x.x.1) - Bug fixes, backwards compatible
