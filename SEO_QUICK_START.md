# SEO Quick Start Guide

## 🚀 Get Started in 30 Minutes

This is your quick-start checklist to get SafariSmart Kenya ranking on Google.

---

## ✅ IMMEDIATE ACTIONS (Do Today)

### 1. Google Search Console (15 minutes)
```
1. Go to: https://search.google.com/search-console
2. Click "Add Property"
3. Enter: safarismart.co.ke
4. Verify ownership:
   - Option A: HTML tag (add to base.html <head>)
   - Option B: DNS record (add TXT record)
5. Submit sitemap: https://safarismart.co.ke/sitemap.xml
6. Request indexing for:
   - Homepage: /
   - Destinations: /destinations/
   - Top 5 destination pages
```

### 2. Bing Webmaster Tools (10 minutes)
```
1. Go to: https://www.bing.com/webmasters
2. Click "Add Site"
3. Enter: safarismart.co.ke
4. Import from Google Search Console (easiest)
5. Or verify manually
6. Submit sitemap
```

### 3. Test Your SEO (5 minutes)
```
□ Google PageSpeed Insights
  https://pagespeed.web.dev/
  Test: safarismart.co.ke
  Target: 90+ score

□ Google Mobile-Friendly Test
  https://search.google.com/test/mobile-friendly
  
□ Google Rich Results Test
  https://search.google.com/test/rich-results
  Test your homepage and a destination page
```

## 📊 VERIFY IMPLEMENTATION

### Check These URLs Work:
```
✓ https://safarismart.co.ke/sitemap.xml
✓ https://safarismart.co.ke/robots.txt
✓ https://safarismart.co.ke/destinations/
✓ https://safarismart.co.ke/destinations/maasai-mara/
```

### Check Meta Tags (View Page Source):
```html
✓ <title> tag present and unique
✓ <meta name="description"> present
✓ <link rel="canonical"> present
✓ Open Graph tags present
✓ Twitter Card tags present
✓ Structured data (JSON-LD) present
```

### Check Structured Data:
```
1. Go to any page
2. Right-click > View Page Source
3. Search for: "application/ld+json"
4. Should see:
   - TravelAgency schema (all pages)
   - TouristDestination schema (destination pages)
   - Trip schema (itinerary pages)
   - FAQPage schema (homepage)
   - BreadcrumbList schema (where applicable)
```

## 🚨 COMMON ISSUES & FIXES

### Issue: Pages not indexed
**Fix:**
1. Check robots.txt allows crawling
2. Submit sitemap again
3. Request indexing in Search Console
4. Check for crawl errors

### Issue: Low performance score
**Fix:**
1. Optimize images (WebP format)
2. Enable caching
3. Use CDN (Cloudflare free tier)
4. Minify CSS/JS

### Issue: No rich snippets
**Fix:**
1. Test with Rich Results Test
2. Check JSON-LD syntax
3. Ensure all required fields present
4. Wait 1-2 weeks for Google to process

### Issue: High bounce rate
**Fix:**
1. Improve page load speed
2. Add engaging content above fold
3. Clear call-to-action
4. Better mobile experience
