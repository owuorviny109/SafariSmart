Task 2.4 Complete: Budget Selection

SUMMARY
-------
Implemented budget selection step with interactive slider and
budget category selection. Calculates per-person costs automatically.

FEATURES IMPLEMENTED
--------------------
1. Budget Slider
   - Range: KSh 10,000 - 500,000
   - Step: KSh 5,000 increments
   - Real-time value display
   - Smooth gradient background

2. Per-Person Calculation
   - Automatically divides by total travelers
   - Updates in real-time as slider moves
   - Displays formatted numbers with commas

3. Budget Categories
   - Budget (KSh 10k - 50k)
   - Mid-Range (KSh 50k - 150k)
   - Luxury (KSh 150k+)
   - Visual cards with icons
   - Auto-suggestion based on amount

4. Validation
   - Minimum budget: KSh 10,000
   - Maximum budget: KSh 500,000
   - Category must be selected
   - Server-side validation in WizardService
   - Client-side validation in JavaScript

5. User Experience
   - Trip summary showing all previous selections
   - Real-time budget updates
   - Auto-select category suggestion
   - Visual feedback on selection
   - Progress indicator (80%)

SERVICE LAYER
-------------
Extended WizardService with:
- save_budget(amount, category)
- get_budget_data()
- _validate_budget() - comprehensive validation

Validation Rules:
- Budget must be between KSh 10,000 and 500,000
- Category must be: budget, mid-range, luxury
- Type checking for integers and strings

VIEW LAYER
----------
Created BudgetSelectionView (Class-Based View):
- Follows DescriptiveNameView pattern
- GET: Display slider and categories
- POST: Validate and save to session
- Calculates per-person budget
- Error handling with user-friendly messages
- Pre-fills data if returning to step
